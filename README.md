# Valheim AutoClicker

A lightweight autoclicker made for Valheim.

It works well in-game, stays simple, and gives you flexible control over how clicks are sent. You can tune the click speed, hold duration, activation hotkey, and mouse button. This makes it useful for both **attack** actions with the left mouse button and **block** actions with the right mouse button.

## Features

- Lightweight Windows autoclicker.
- Works smoothly in Valheim.
- Flexible CPS and mouse hold duration settings.
- Supports both left mouse button and right mouse button.
- Can be used for attack or block behavior.
- Custom activation hotkey.
- Simple desktop interface.

## Download / EXE Version

The `.exe` file is the compiled version of the program. Use it if you do not have Python installed or if you simply want to run the autoclicker without setting up a Python environment.

If the executable is in the `dist` folder, run:

```text
dist/valheim_autoclicker.exe
```

## How to Use

1. Run the application or the compiled `.exe` file.
2. Set the desired CPS value.
3. Set the hold duration in milliseconds.
4. Select the mouse button:
   - `LMB` for attack.
   - `RMB` for block.
5. Press `Enable` or use the activation hotkey.

The default hotkey is `F6`.

## Notes

This tool is designed for Windows because it uses the Windows API to send mouse input.

Use it responsibly and only in ways that match the rules of the game or server you are playing on.

# Valheim AutoClicker

Легковесный автокликер для Valheim.

Он отлично работает в игре, остается простым и при этом гибко настраивается. Можно настроить скорость кликов, длительность удержания кнопки, горячую клавишу активации и кнопку мыши. Благодаря этому автокликер можно использовать как для **атаки** через левую кнопку мыши, так и для **блока** через правую кнопку мыши.

## Возможности

- Легковесный автокликер для Windows.
- Отлично работает в Valheim.
- Гибкая настройка CPS и времени удержания кнопки.
- Поддержка левой и правой кнопки мыши.
- Можно использовать для атаки или блока.
- Настраиваемая горячая клавиша.
- Простой графический интерфейс.

## Скачать / EXE-версия

Файл `.exe` - это уже скомпилированная версия программы. Используйте его, если у вас не установлен Python или если вы просто хотите запустить автокликер без настройки Python-окружения.

Если исполняемый файл находится в папке `dist`, запустите:

```text
dist/valheim_autoclicker.exe
```

## Как использовать

1. Запустите приложение или готовый `.exe` файл.
2. Укажите нужное значение CPS.
3. Укажите длительность удержания кнопки в миллисекундах.
4. Выберите кнопку мыши:
   - `LMB` для атаки.
   - `RMB` для блока.
5. Нажмите `Enable` или используйте горячую клавишу.

Горячая клавиша по умолчанию: `F6`.

## Примечания

Инструмент предназначен для Windows, потому что использует Windows API для отправки ввода мыши.

Используйте его ответственно и только так, как разрешено правилами игры или сервера.
